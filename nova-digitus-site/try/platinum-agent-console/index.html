      Failure alerts
      
          
      
          
      When any run fails, the relay posts a message to ALERT_WEBHOOK_URL. Slack incoming webhooks and Discord webhooks both work. Set it in the server's .env and restart.
      
        
      
        
      
          
      Inbound webhooks
      
          
      Every pipeline has its own URL and secret, so forms, Stripe, Zapier or another n8n flow can start it. Find them on the Pipelines tab once the relay is connected.
