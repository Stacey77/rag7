# Stacey Williams - Digital Business Card

A modern, Progressive Web App (PWA) digital business card for Stacey Williams, Certified Service Technician at Mercedes Benz Of Collierville.

## Features

- 📱 **Progressive Web App**: Install on any device for offline access
- 🎨 **Modern Design**: Clean, professional interface with gradient backgrounds
- 📞 **Direct Contact**: Quick access to phone, email, and location
- 💾 **Offline Support**: Service worker caching for offline functionality
- 📲 **Mobile Optimized**: Responsive design that works on all screen sizes

## Installation

### As a PWA (Recommended)

1. Visit the digital business card website
2. Click the "Install App" button
3. Follow your browser's installation prompts
4. Access the card anytime from your home screen

### For Development

```bash
# Clone the repository
git clone https://github.com/Stacey77/rag7.git

# Navigate to the directory
cd rag7

# Serve the files using any static file server
# For example, using Python:
python -m http.server 8000

# Or using Node.js http-server:
npx http-server
```
